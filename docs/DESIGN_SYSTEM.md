# DESIGN_SYSTEM.md

## Direction
**High-Fidelity UI/UX × Creative SaaS Landing Page × Premium Scientific Editorial.**

The visual identity should feel like a world-class research institution redesigned by a premium SaaS product studio.

## Brand
Product name: POLARIS
Tagline: "The living archive of polar science."

## Color tokens
Base: near-black / deep navy.
Surface: blue-black elevated panels.
Primary accent: ice cyan.
Secondary accent: cool indigo.
Text: warm-white.
Muted text: blue-grey.
Use gradients only for hero atmosphere and subtle highlights.

## Typography
Display: Geist / Inter Tight style, very large and tight.
Body: Inter.
Numbers: tabular numerals where useful.
Headings should be short, confident and editorial.

## Layout
- 12-column desktop grid.
- Max content width ~1280px.
- Mobile-first.
- 24–32px card radius.
- 1px low-contrast borders.
- Dense dashboards; spacious editorial pages.
- Strong visual hierarchy.

## Components
Buttons: compact, confident, high contrast.
Cards: image-led with subtle hover elevation.
Tables: clean, sticky headers where useful.
Chips: small rounded metadata pills.
Search: command-palette feel.
Navigation: translucent sticky header.
Hero: oversized statement + atmospheric polar imagery + floating stats.

## Motion
Use Framer Motion.
- Page entrance: 250–450ms.
- Hover: 150–250ms.
- Stagger lists lightly.
- Never animate everything.
- Respect reduced-motion preference.

## UX rules
- One primary CTA per section.
- Never use gradients behind body text.
- Never use excessive glassmorphism.
- Never use emoji as UI icons.
- Use Lucide icons.
- Always design loading, empty, error and success states.
- Maintain WCAG-friendly contrast.

## Landing page composition
1. Announcement bar
2. Glass navigation
3. Cinematic hero with "Explore the edge of knowledge."
4. Trusted/impact metrics
5. Featured expedition
6. Research repository preview
7. Science story editorial split
8. Media mosaic
9. Interactive timeline
10. CTA/footer

## Admin
Use the same design language but prioritize speed, clarity and density.
