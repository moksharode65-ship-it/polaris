# POLARIS — SIH26063

Premium polar-science knowledge repository and media dissemination portal.

## MVP routes
- `/` — landing
- `/research` — repository
- `/research/[id]` — resource detail
- `/expeditions` — expedition directory
- `/expeditions/[id]` — expedition detail
- `/media` — media gallery
- `/stories` — editorial science stories
- `/admin` — content dashboard

## Design direction
High-fidelity UI/UX + creative SaaS landing page + premium scientific editorial.
